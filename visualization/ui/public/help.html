Visualizer Help

Learn the basic workflow for creating a visualization and how each tool works.

Overall Workflow

1. Import an Image

Start by importing an image into the visualizer. Supported file types include SVG, PNG, and JPEG. Importing a new image will replace the current visualization, so make sure to save or export your work first if needed.

2. Edit the Visualization

After importing an image, use the tools menu to highlight elements, make elements selectable, create new interactive areas, or edit details. These tools let you control how participants interact with the visualization in a survey.

3. Save Your Work

Work is automatically saved as you make changes. You can also use the save button to manually store your changes. Saving keeps your edited visualization available for later use in your survey design.

4. Export the Visualization

Use the export button to download the visualization as an SVG file. This is useful if you want to keep a copy outside the application.

Tools Guide

Highlight Elements

Click on an element to highlight it. Highlighting is useful when you want to draw attention to part of the visualization, especially for short answer or multiple choice questions where the participant does not directly select the visual element.

Set Selectable

Use this tool to control whether an element can be selected by a participant. Dark blue elements are selectable, while cyan elements are not selectable. Click an element to toggle its selectability.

Create Box

Click and draw to create a rectangular interactive area. The box is selectable by default and can be used when the original image does not already have a selectable element in the area you need.

Create Lasso

Use this tool to draw a custom-shaped interactive area. This is helpful when the area you want participants to select is not a simple rectangle.

Delete Added Elements

Use this tool to delete elements that were manually added with the Create Box or Create Lasso tools. This does not remove the original image itself.

Edit Details

Use this tool to edit information connected to an element, such as its label or details shown when users interact with it.
